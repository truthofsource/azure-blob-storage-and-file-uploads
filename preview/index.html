A storage location is not permission to open a file.

The application checks the user and document type before opening a file. HR does not automatically get Payroll access. Employee forms have separate access checks for the relevant person.

RoleTypes allowed through the document library

Version history

Keeps earlier file versions. Check the file and its saved details before restoring one.

30-day soft deletion

The setup provides a recovery period for deleted files and collections. It does not restore the whole application.

Audit logs

Records of file reads, changes and deletions go to a central logging location. The application also records business access.

Direct access to the file store is separate from access through the application. Both network rules and account permissions must allow the connection.
